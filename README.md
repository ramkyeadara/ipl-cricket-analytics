# IPL Cricket Analytics & Score Prediction

## Why I built this

I have been working with data for the last 7 years, data management, 
ETL pipelines, SQL, stakeholder delivery. But honestly, I felt I was 
missing the bigger picture. I could move data, but I could not fully 
analyse it, model it, or build something end to end on my own.

With AI tools, cloud platforms, and modern data engineering stacks 
becoming so powerful, I believe a data engineer today should be able 
to do it all, engineering, analytics, and data science. Not just one 
piece of the puzzle.

So I decided to build something from scratch. And the first project 
you do should be something you genuinely know and love.

I am a cricket enthusiast. I know the sport inside and out, the 
players, the strategies, the numbers behind the game. IPL data made 
perfect sense. Real data, real matches, real insights.

## What this project covers

- Data ingestion: loading raw ball-by-ball IPL data using Python
- Data cleaning: using pandas to clean and structure the data
- Medallion architecture: organising data into Bronze, Silver 
  and Gold layers on Databricks
- Analytics: player stats, venue analysis, team performance
- ML model: predicting first innings score based on venue, 
  teams and player form
- Dashboard: Power BI dashboard showing analytics and 
  win probability batting first

## Dataset
- Source: Cricsheet.org
- 1,226 IPL matches
- 291,574 balls of ball-by-ball data
- Seasons 2008 to 2024

## Tech Stack
- Python, pandas
- Databricks + Delta Lake
- Azure Blob Storage
- Power BI
- scikit-learn
